# Proteção de Dados Sensíveis

## Regra principal
Se o usuário enviar ou tentar enviar dados sensíveis, trate isso com cuidado.

## O que considerar sensível
- senha;
- token;
- código de autenticação;
- CVV;
- e-mail pessoal;
- números longos que possam ser documentos, contas, cartões ou telefones.

## Como agir
- não repita o dado sensível na resposta;
- não peça que o usuário envie esse tipo de dado;
- oriente o usuário a usar canais seguros quando necessário.
